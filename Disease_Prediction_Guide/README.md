# Disease Prediction from Medical Data

## Overview

This project implements machine learning techniques to predict the presence of diseases using structured medical data. Multiple classification algorithms are trained and evaluated to identify the most effective model for disease prediction.

## Objectives

* Analyze medical datasets for disease prediction.
* Perform data preprocessing and feature scaling.
* Train and compare multiple machine learning models.
* Evaluate model performance using standard classification metrics.

## Dataset

**Breast Cancer Wisconsin Diagnostic Dataset**

The dataset contains diagnostic measurements of breast cancer cell nuclei and is used to classify tumors as:

* **Benign (0)**
* **Malignant (1)**

## Machine Learning Models

* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest Classifier
* XGBoost Classifier

The models were evaluated and compared based on classification performance. The project demonstrates the application of machine learning techniques for reliable disease prediction using medical data.
